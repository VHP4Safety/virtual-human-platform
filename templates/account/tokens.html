Writing records with a token

Fields are named as in schema.org; a link is {"@id": "https://..."}. The record is checked against the model and shown on its page at once.

curl -X PUT {{ request.url_root }}api/tools/my-tool \
  -H "Authorization: Bearer vhp_..." \
  -H "Content-Type: application/json" \
  -d '{"name": "My tool", "description": "What it does.",
       "url": {"@id": "https://example.org"}}'

With POST /api/tools, the address is made from the name. With DELETE /api/tools/my-tool, the record is removed. With POST /api/images, an image is uploaded. The saved record is at {{ request.url_root }}tools/my-tool.jsonld. The same is done with a form in the record editor.
